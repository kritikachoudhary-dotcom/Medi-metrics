# MediMetrics
### Health Data Analysis and Visualization System Using Python and Tkinter

**MediMetrics** is a Python-based desktop application developed as an MCA mini project. It helps users explore health-related sample data through statistical calculations, tables and graphical visualizations.

## Features
- Dashboard with health statistics
- Patient record management and search
- Age and gender visualization
- Blood pressure and cholesterol analysis
- CSV dataset upload
- Data cleaning and statistical calculations

## Technologies Used
- Python
- Tkinter
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Structure
- `main.py` – Main application and graphical interface
- `analysis.py` – Data cleaning and analysis functions
- `health_data.csv` – Sample dataset
- `requirements.txt` – Required Python libraries

## Installation and Execution

1. Clone this repository.
2. Install the required libraries:

   `pip install -r requirements.txt`

3. Run the application:

   `python main.py`

## Dataset
The project uses fictional sample data for educational and demonstration purposes only.

## Disclaimer
MediMetrics is an academic project. It is not a medical diagnosis or treatment system.
